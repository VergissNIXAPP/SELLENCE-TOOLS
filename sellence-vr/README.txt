SELLENCE-VR

Funktionen:
- Marktfoto aufnehmen oder laden
- Food Module visuell ins Bild setzen
- Module frei positionieren, skalieren und auf dem Boden drehen
- Module zusätzlich nach vorne, hinten, links oder rechts ausrichten
- Zusätzliche Kippung oben/unten für bessere Perspektive
- Händler-Provision live berechnen
- PNG Export der fertigen Visualisierung
- Projekt Export / Import als JSON
- PWA / installierbar

Hinweise zur Provision:
- Provisionen wurden aus dem importierten PICOS POS Rechner übernommen.
- Für VEEV Grab & Go Display war im importierten Rechner keine direkte Rate vorhanden.
  Deshalb steht dort standardmäßig 0,00 € und kann manuell angepasst werden.
